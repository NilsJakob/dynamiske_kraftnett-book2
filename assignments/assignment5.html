Øving 5: Modellering med Gauss#

Læringsmål#

Etter øvingen skal du kunne:

  • bruke en generell Gauss-modell til å beskrive døgnprofil,

  • implementere modellen i Python,

  • lete opp lastdata fra kilde (Les: en for deg ‘ny’ kilde)

  • tilpasse modellen til observerte data,

  • bruke Git til å dokumentere arbeidsprosessen,

  • diskutere modellvalg ved hjelp av bias-varians-avveiningen.

Oppgave 1: Den generelle modellen#

Vi antar at belastningen kan beskrives som

\[ L(t) = L_0 + \sum_{i=1}^{n} A_i \exp\!\left(-\frac{(t-\mu_i)^2}{2\sigma_i^2}\right). \]

Der:

  • \(L_0\) er grunnlasten,

  • \(A_i\) er amplituden til komponent \(i\),

  • \(\mu_i\) er tidspunktet for topp,

  • \(\sigma_i\) er bredden på komponenten.

Oppgaver#

  1. Forklar med egne ord hvordan parameterne \(A_i\), \(\mu_i\) og \(\sigma_i\) påvirker kurven.

  2. Implementer modellen i Python.

  3. Eksperimenter med parameterverdiene og dokumenter observasjonene.

Oppgave 2: Lastdata#

Finn en døgnprofil for elektrisk belastning fra en valgfri, offentlig tilgjengelig kilde.

Krav#

Oppgi:

  • datakilde,

  • dato,

  • lenke til datasettet.

Eksempler på kilder:

  • SSB

  • Elhub

  • Nord Pool

  • Open Power System Data

  • andre åpne datasett

Oppgave 3: Modellering#

Bruk den generelle modellen til å beskrive den valgte døgnprofilen.

Anbefaling#

Start og dokumenter med tre komponenter:

  • nattperiode,

  • morgentopp,

  • kveldstopp.

Du står fritt til å bruke flere eller færre komponenter dersom dette gir en bedre modell.

Leveranse#

Vis:

  • den endelige ligningen,

  • parameterverdiene,

  • et plott med observerte data,

  • et plott med modellert kurve,

  • et plott der begge vises samtidig.

Oppgave 4: Git#

Alt arbeid skal versjonskontrolleres i Git.

Krav#

Repo skal inneholde:

  • Python-kode

  • datafil(er)

  • figurer som genereres i analysen

  • README

Du skal gjøre flere commits underveis og skrive meningsfulle commit-meldinger.

Eksempler:

git commit -m "Import load data"
git commit -m "Implement Gaussian load model with 3 components"
git commit -m "Tune evening peak"
git commit -m "Add bias variance discussion"

Oppgave 6: Kritisk vurdering#

Diskuter modellens styrker og svakheter.

Stikkord:

  • Hvilke deler av døgnkurven beskrives godt?

  • Hvilke deler beskrives dårlig?

  • Er toppene symmetriske?

  • Hvordan påvirkes modellen av vær og sesong?

  • Hva ville skjedd dersom flere Gauss-komponenter ble lagt til?

Oppgave 7: Bias-varians-avveining#

Vi antar at det finnes en ukjent sann sammenheng

\[ y=f(x)+\varepsilon, \]

og at modellen vår er

\[ \hat f(x). \]

Diskuter:

  1. Hva representerer \(f(x)\)?

  2. Hva representerer \(\hat f(x)\)

  3. Hva skjer dersom modellen har for få komponenter?

  4. Hva skjer dersom modellen har svært mange komponenter?

  5. Hvor mener du at din modell befinner seg på skalaen mellom høy bias og høy varians?

Avslutt med å kommentere utsagnet:

En modell med høy bias lærer for lite av dataene. En modell med høy varians lærer for mye av dataene. En god modell lærer akkurat nok.
